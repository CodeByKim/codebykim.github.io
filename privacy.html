Todo 개인정보처리방침

시행일: 2026년 10월 30일

Todo(이하 "앱")는 사용자의 할 일과 일정을 관리하는 Windows 앱입니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 정보와 저장 위치

앱은 개발자가 운영하는 서버를 두지 않으며, 사용자의 정보를 개발자에게 전송하지 않습니다. 모든 데이터는 다음 두 곳에만 저장됩니다.

  • 사용자의 PC: 할 일, 일정, 메모, 설정이 PC 안의 데이터 파일에 저장됩니다.
  • 사용자 본인의 Google 계정(Google 동기화를 켠 경우): 아래 2항의 권한 범위 안에서 저장됩니다.

2. Google 계정 데이터 사용

사용자가 Google 계정으로 로그인하면 앱은 다음 권한을 요청하고, 동기화 목적으로만 사용합니다.

권한사용 목적
Google Calendar앱의 일정과 사용자의 기본 캘린더 일정을 서로 읽고 쓰기
Google Tasks앱의 할 일과 Google Tasks의 할 일·목록을 서로 읽고 쓰기
Google Drive 앱 전용 폴더(appDataFolder)Google Tasks에 담기지 않는 정보(시간, 반복, 태그, 체크리스트 등)를 사용자 본인의 Drive 안 앱 전용 숨김 폴더에 저장. 앱은 Drive의 다른 파일에 접근하지 않습니다.

Google 로그인 정보(인증 토큰)는 사용자의 PC에만 저장됩니다.

앱이 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

Todo's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. 제3자 제공

앱은 사용자의 정보를 판매하거나 제3자에게 제공하지 않으며, 광고나 분석 목적으로 사용하지 않습니다.

4. 보관 기간과 삭제

  • PC의 데이터는 사용자가 앱을 삭제하거나 데이터 폴더(%LocalAppData%\TodoApp)를 지우면 함께 삭제됩니다.
  • 앱 설정에서 Google 연결을 해제하면 PC에 저장된 인증 토큰이 삭제되고 권한이 취소됩니다.
  • Google 계정 쪽 권한은 언제든지 Google 계정 → 보안 → 서드 파티 연결에서 해제할 수 있습니다.
